# Code of Conduct

[中文版](CODE_OF_CONDUCT_zh.md)

## Our Standards

This project is a curated resource. To keep it useful, we hold contributors to these standards:

- **Be honest.** Only submit providers you have personally tested. Do not fabricate test results or provider capabilities.
- **Be useful.** Every addition should make the list more valuable to someone looking for a free LLM API. Don't add noise.
- **No spam or self-promotion.** Do not submit your own service unless it genuinely meets all criteria. Do not submit referral links disguised as provider entries.
- **No fake providers.** Submitting non-existent providers, providers that are paid-only, or providers that require payment info for "free" access is a waste of everyone's time and will result in your PR being closed and future PRs being scrutinized more heavily.
- **Respect the list's purpose.** This is not a general LLM resource list. It is specifically for free API providers that are verified and useful. If a provider doesn't meet the criteria, it doesn't belong here, regardless of how good it is.

## Enforcement

Pull requests that violate these standards will be closed. Repeated violations (especially submitting fake providers) will result in being blocked from contributing.

## Questions?

Open an issue if you have concerns about a provider already listed, or if you're unsure whether something qualifies.
